# Project Management Backend

## Features

- NestJS
- Prisma ORM
- JWT Auth
- RBAC
- Websocket Realtime
- Task Watchers
- Mentions
- Email Notifications
- SLA Tracking
- Fulltext Search

## Install

```bash
npm install
```

## Prisma

```bash
npx prisma generate
npx prisma migrate dev
```

## Run

```bash
npm run start:dev
```
